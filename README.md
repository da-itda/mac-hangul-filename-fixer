# 한글본드 — 맥 한글 파일명 깨짐·자소 분리 해결

한글본드는 macOS에서 자소가 분리되어 보이는 파일명과 폴더명을 찾아 NFC 형태로 정리하는 메뉴바 앱입니다. 파일 내용은 바꾸지 않고 이름만 변경합니다.

## 다운로드

- **macOS Apple silicon용 최신 공개 DMG:** [GitHub 최신 릴리스에서 다운로드](https://github.com/da-itda/mac-hangul-filename-fixer/releases/latest)
- [뉴어 홈페이지](https://newer.co.kr/)
- 설치된 앱의 `정보` 탭에서 자동 업데이트를 확인할 수 있습니다.

현재 다운로드는 Apple silicon(arm64)용입니다. Intel Mac용 빌드는 제공하지 않습니다.

## 설치 및 시작

1. 위의 DMG를 내려받아 엽니다.
2. 디스크 이미지 안의 `한글본드.app`을 `응용 프로그램` 폴더로 옮깁니다.
3. 앱을 실행하고 설정 화면의 `폴더` 탭에서 `+`를 눌러 정리할 폴더를 추가합니다.
4. `검사`를 눌러 변환 예정 이름을 확인합니다.
5. 필요한 항목만 선택한 뒤 `선택 항목 정리`를 누릅니다.

## 대량 파일 처리

- 검사 결과에서 `모두 선택`, `모두 해제`를 사용하거나 원하는 파일·폴더만 선택할 수 있습니다.
- 검사나 정리 중 `중단`을 누르면 현재 항목을 안전하게 마친 뒤 멈춥니다. 검사 중단 시 그때까지 확인한 결과를 선택해 정리할 수 있습니다.
- 작업 중 다른 탭으로 이동해도 검사는 계속됩니다. 정리는 백그라운드에서 진행되며 진행 상황과 중단 버튼을 확인할 수 있습니다.
- 특정 폴더만 처리하려면 `폴더` 탭에서 그 폴더를 선택하고 검사합니다. 하위 폴더를 건너뛰려면 해당 폴더의 `하위 폴더 포함`을 끕니다.

자세한 내용은 [한글 사용 설명서](docs/USER_GUIDE.md)를 참고하세요.

## 안전 원칙

- 파일 내용은 변경하지 않고 파일명과 폴더명만 NFC로 정규화합니다.
- 검사 후 바뀔 항목을 먼저 확인하고, 정리할 대상을 선택할 수 있습니다.
- 이름 충돌이 있으면 기존 항목을 덮어쓰지 않습니다.
- 지정한 폴더만 검사합니다. 자동 감시를 켠 경우에는 저장된 폴더 중 감시가 켜진 폴더만 처리합니다.
- 파일을 내려받거나 저장하는 중일 수 있으므로, 변환 전 대기 시간을 1초·3초·5초·10초 중에서 설정할 수 있습니다.

## 자동 감시와 업데이트

`일반` 탭에서 `자동 감시`를 켜면 감시 대상으로 표시된 폴더의 새 파일을 확인합니다. 로그인할 때 앱을 함께 실행하려면 `로그인 시 자동 실행`을 켭니다.

새 버전과 다운로드 파일은 [GitHub Releases](https://github.com/da-itda/mac-hangul-filename-fixer/releases)에서 관리합니다. 설치된 앱은 GitHub의 업데이트 정보를 확인하고, 서명이 검증된 업데이트를 설치한 뒤 다시 시작합니다.

## 웹에 올릴 때 파일명이 깨진다면 (브라우저 확장)

맥에서 Chrome으로 파일을 올리면 디스크의 이름이 정상이어도 `ㅎㅏㄴㄱㅡㄹ.pdf`처럼 자소가 분리되어 올라갈 수 있습니다. 맥용 Chrome이 업로드할 때 이름을 다시 분리하기 때문입니다. 한글본드 브라우저 확장을 설치하면 업로드할 때 이름을 NFC로 바꿔 보냅니다. Safari는 브라우저가 직접 NFC로 바꿔 보내므로 확장이 필요 없습니다.

자세한 내용은 [브라우저 확장 안내](docs/BROWSER_EXTENSION.md)를 참고하세요.

## 문제가 해결되지 않을 때

이 앱은 Unicode NFC/NFD 자소 분리로 생긴 이름을 정리합니다. 파일명이 CP949 등 다른 인코딩 문제로 완전히 다른 문자로 보이는 경우에는 해결되지 않을 수 있습니다. 처리 내역은 앱의 `로그` 탭에서 확인하세요.
