# 한글 파일명 NFC 자동 정리 프로그램 문서

이 폴더는 Codex가 프로젝트 개발 전에 반드시 읽어야 할 기획/정책/UX 문서 모음입니다.

현재 기능 테스트와 릴리스 절차는 [`docs/README.md`](docs/README.md)에서 확인합니다.

## 읽는 순서

1. `GOAL.md`
2. `DEVELOPMENT_POLICY.md`
3. `UI_UX_SPEC.md`
4. `MVP_CHECKLIST.md`
5. `TEST_CASES.md`
6. `CODEX_START_PROMPT.md`

## 프로젝트 핵심

이 프로그램은 macOS와 Windows에서 발생하는 한글 파일명 자소 분리 문제를 해결하기 위한 유틸리티입니다.

핵심 기능은 사용자가 지정한 폴더 안의 NFD 형태 한글 파일명/폴더명을 NFC 형태로 안전하게 변경하는 것입니다.

## 현재 확정된 UI 방향

- Unclutter의 내려오는 패널 UI는 사용하지 않습니다.
- 현재 프로그램은 설정 화면 중심으로 구성합니다.
- macOS는 메뉴바에 아이콘을 표시하되, 클릭 시 간단 메뉴와 설정 화면 진입만 제공합니다.
- Windows는 트레이 아이콘을 표시하되, 클릭 시 간단 메뉴와 설정 화면 진입만 제공합니다.
- 실제 주요 조작은 설정 화면에서 진행합니다.

## 가장 중요한 개발 원칙

- 파일 내용은 절대 수정하지 않습니다.
- 파일명과 폴더명만 NFC로 정규화합니다.
- 충돌 발생 시 덮어쓰지 않습니다.
- 시스템 전체를 무조건 감시하지 않습니다.
- 사용자가 선택한 폴더 중심으로 동작합니다.
- 자동 변환보다 안정성이 우선입니다.
