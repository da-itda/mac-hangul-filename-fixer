# 한글본드 사용 설명서

한글본드는 맥과 다른 운영체제 사이에서 파일을 주고받을 때 한글 파일명이나 폴더명이 `ㅎㅏㄴㄱㅡㄹ`처럼 자소 단위로 나뉘어 보이는 문제를 정리하는 macOS 메뉴바 앱입니다.

현재 공개 다운로드는 Apple silicon(arm64)용입니다. 파일 내용은 변경하지 않고 이름만 NFC 형태로 바꿉니다.

## 다운로드 및 설치

1. [GitHub 최신 릴리스](https://github.com/da-itda/mac-hangul-filename-fixer/releases/latest)에서 macOS Apple silicon용 DMG를 다운로드합니다.
2. 내려받은 DMG를 열고 `한글본드.app`을 `응용 프로그램`으로 옮깁니다.
3. `응용 프로그램`에서 한글본드를 실행합니다.

앱의 최신 버전은 [뉴어 홈페이지](https://newer.co.kr/)에서 확인할 수 있습니다. 앱 안에서는 `정보` 탭의 `확인` 버튼으로 업데이트할 수 있습니다.

## 폴더를 검사하고 정리하기

1. 설정 화면에서 `폴더` 탭을 엽니다.
2. `+`를 눌러 검사할 폴더를 추가합니다. 여러 폴더를 한 번에 추가할 수도 있습니다.
3. 목록에서 처리할 폴더를 선택합니다.
4. `하위 폴더 포함`이 켜져 있으면 하위 폴더도 검사합니다. 현재 폴더만 검사하려면 이 옵션을 끕니다.
5. `검사`를 눌러 변환될 이름을 확인합니다.
6. 정리하지 않을 항목의 선택을 해제합니다. `모두 선택`과 `모두 해제`도 사용할 수 있습니다.
7. `선택 항목 정리`를 눌러 이름을 변경합니다.

폴더를 검사할 때 하위 폴더가 함께 선택될 수 있습니다. 정리 전에 결과 목록에서 선택 상태를 확인하세요. 목록이 길면 `더 보기`로 나머지 항목을 확인할 수 있습니다.

## 대량 처리와 중단

파일이 많은 폴더도 검사와 정리를 진행하면서 앱의 다른 탭을 사용할 수 있습니다. 정리 작업은 백그라운드에서 계속되고 진행 건수와 진행 막대가 표시됩니다.

- 작업을 멈추려면 진행 영역의 `중단`을 누릅니다.
- 정리는 현재 처리 중인 항목을 안전하게 마친 다음 멈춥니다.
- 검사 중단 시 이미 확인한 항목은 결과에 남으므로, 그중 필요한 항목만 선택해 정리할 수 있습니다.
- 특정 폴더만 바꾸려면 그 폴더를 선택해 검사하고, 결과에서 필요한 파일과 폴더만 선택합니다.

## 자동 감시

`일반` 탭에서 `자동 감시`를 켜면 `폴더` 탭에서 감시가 켜진 폴더의 새 파일을 정리합니다. 폴더별 감시를 끄거나 켤 수 있습니다. 자동 감시를 사용하지 않을 때는 끄고 수동으로 검사할 수 있습니다.

`파일 저장 후 대기`는 새 파일이 완전히 저장될 시간을 주는 설정입니다. 기본값은 3초이며, 1초·5초·10초로 바꿀 수 있습니다. 파일을 저장하는 앱이나 저장 장치가 느리면 대기 시간을 늘려 보세요.

맥에 로그인할 때 한글본드를 자동으로 실행하려면 `로그인 시 자동 실행`을 켭니다.

## 로그와 설정

- `로그` 탭에는 최근 처리 결과 10개가 표시됩니다.
- 설정과 전체 작업 로그는 앱의 `정보` 탭에서 각각 파일 위치를 확인할 수 있습니다.
- 앱을 다시 실행해도 등록한 폴더와 설정이 저장됩니다.

## 알아둘 점

- 한글본드는 지정한 파일의 내용이나 내부 문자를 바꾸지 않습니다. 파일명과 폴더명만 처리합니다.
- 같은 이름이 이미 있으면 기존 파일을 덮어쓰지 않습니다. 충돌이 생긴 항목은 로그에서 확인하세요.
- 다운로드 또는 복사 중인 파일은 정리 대상에서 건너뛸 수 있습니다. 저장이 끝난 뒤 다시 검사하거나 자동 감시를 사용하세요.
- 이 앱은 NFC/NFD 자소 분리 문제를 처리합니다. 압축 파일의 문자 인코딩 오류나 CP949 등 다른 방식으로 깨진 파일명은 대상이 아닙니다.
